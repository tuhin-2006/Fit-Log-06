# FitLog

FitLog is a modern workout library and workout planning web application. Users can explore workouts, view workout details, save workouts, create a personal workout plan, and track completed workouts.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Next.js App Router
- REST API
- Local Storage

## Key Features

1. **Workout Library**  
   Browse different workouts with images, muscle groups, equipment, difficulty, duration, calories, and ratings.

2. **Workout Details**  
   View complete workout information including description, difficulty, duration, calories, sets, reps, rating, and instructions.

3. **My Plan**  
   Add workouts to today's workout plan and manage planned exercises.

4. **Save Workouts**  
   Save workouts for later and access them from the Saved section.

5. **Workout Progress**  
   Mark workouts as completed and keep workout data saved in Local Storage.

## Pages

- `/` - Workout Library
- `/workouts/[id]` - Workout Details
- `/my-plan` - My Plan and Saved Workouts

## API
