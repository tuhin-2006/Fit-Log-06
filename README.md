# 🏋️ FitLog

FitLog is a modern workout library and workout planning web application built with Next.js and TypeScript. It helps users discover workouts, view detailed exercise information, create a personal workout plan, save workouts for later, and track completed exercises.

---

## 🚀 Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Next.js App Router
- REST API
- Local Storage

---

## ✨ Key Features

### 1. 🏋️ Workout Library

Users can browse a collection of workouts with:

- Workout images
- Muscle groups
- Equipment
- Difficulty level
- Duration
- Calories burned
- Rating

### 2. 📋 Workout Details

Each workout has a dedicated details page containing:

- Workout description
- Muscle groups
- Equipment
- Difficulty
- Duration
- Calories
- Sets
- Reps
- Rating
- Step-by-step instructions

### 3. 📅 My Plan

Users can add workouts to their personal daily workout plan and manage their selected exercises from one place.

### 4. ⭐ Save Workouts

Users can save workouts for later and access them from the Saved section.

### 5. ✅ Workout Progress

Users can mark workouts as completed and keep track of their completed exercises.

---

## 📱 Responsive Design

FitLog is designed to provide a responsive experience across:

- Desktop
- Laptop
- Tablet
- Mobile

The layout, navigation, workout cards, plan section, and footer adapt to different screen sizes.

The design includes:

- Modern workout cards

- Workout details page
- Loading states
- Toast notifications
- Personal workout plan
- Saved workouts
- Minimal footer
- Mobile-friendly layout
